# Crater V2 切图素材

依据本次用户提供的 1586×992 设计参考制作。此包为独立准备的新素材，尚未替换当前 App 使用的资源，也未改变已安装版本。

## 文件

- `png/`：26 个 PNG，包括控制台、控制中心、独立 Logo 和 CyberBrick 图标。
- `android-ninepatch/`：14 个可拉伸 `.9.png`，已用 Android aapt2 编译验证。
- `svg/`：12 个矢量图层，含 Logo、网格、摇杆指示环、返航、暂停、锁定、设置、Xbox、Joystick 等。
- `manifest.json`：尺寸、原参考坐标、素材状态、固定边缘、动态颜色和使用约束。

母版与预览位于项目 `design-assets/materials/crater-v2/`。材质母版由内置 image_gen 生成；后续使用 `design-assets/scripts/slice_crater_v2.swift` 按明确坐标裁切、透明轮廓和九宫格规则导出。源图的细微纹理采用 AI 清理重建，并非逐像素完全相同的原图。

## 拼装规则

1. 全屏背景使用 `background.png`；顶栏单独放置 `top_bar`。背景不作为重复平铺纹理使用。
2. 摇杆底座左右各一张，固定槽位已包含在底座内；覆盖独立网格，再叠加动态指示环和滑块。不再重复绘制底座内部槽位。
3. `dial_track` 和 `continuous_track` 横向伸缩时固定两端弯曲；`dial_thumb` 独立移动，竖向拨轮可以旋转同一滑块。`trim_track` 供需要单独装配的内壁槽位使用。
4. 按钮 normal/pressed 共用相同画布尺寸。文字和图标不在位图里。按下使用对应素材；松开恢复 normal，灯光淡出由独立叠加层控制。
5. `video_frame` 中间透明；背景/视频放在它下方。边框只拉伸中段，避免四角变形。
6. 滑动锁定槽与滑块分开，锁定图标和文字独立。连续拨轮不显示数值。两者底部用共同基线定位。
7. 三档开关的 Logo 使用独立 alpha/矢量图层，状态文字由界面绘制；Logo tint 和文字 tint 是两个独立参数。C/N/S 具体颜色等待用户确认，未把猜测颜色烘焙进材质。
8. 1920×1080、1920×1280 使用同一组控件素材与尺寸，通过间距吸收高度差。摇杆底座保持等比例；禁止把整个界面当作一张图拉伸。

## Android 接入

将需要的九宫格文件复制到 `res/drawable-nodpi/` 并使用 `djirc_v2_` 前缀避免名称冲突；不要同时保留同名普通 PNG 和 `.9.png`。其余 PNG 用清晰的独立资源名加载，SVG 可转换为 VectorDrawable；现有控制图标在 UI 库中已有相应 VectorDrawable。

PNG 是母版原生像素裁切，未通过简单放大冒充高分辨率。manifest 的固定边缘单位是素材像素，适配时按目标显示比例换算。

## 控制中心与滑动锁补充

控制中心新增菜单选中、分类普通/选中、卡片普通/选中和操作按钮六种九宫格素材。普通菜单透明，焦点用独立细描边，选中才使用凸起材质；展开箭头、文案和设备图标保持独立。Xbox、Joystick、CyberBrick 统一归入虚拟设备，CyberBrick 使用用户提供的立方体轮廓，预览采用浅色 tint。

滑块使用 `lock_thumb_small.png`，82×71 原生像素、小圆角，与常规按钮协调。锁定后整块组件采用低饱和琥珀色状态叠层（预览配色），触屏不可解锁；同时长按物理 C1 + C2 时原组件变为解锁进度条，满格解锁。松开任意一键、输入断开或丢失时清零。预览暂定持续 2 秒，实际交互尚未接入 App。旧的反向滑动解锁规则被此规则取代。

补充素材及预览通过 `design-assets/scripts/slice_control_center_v2.swift` 生成；先运行基础脚本时，需要随后运行此补充脚本恢复新增 manifest 条目。控制中心预览是素材拼装效果，并非设备实机截图。
