# Device icon sources

The SVG files in this directory are the editable device-category icon sources.
Their geometry is maintained as project-owned,
single-colour line artwork following the selected Iconfont linear collection's
24×24 grid, rounded caps and consistent stroke language. It may be used and
redistributed with this SDK under the repository license.

Android ships equivalent `VectorDrawable` resources so the SDK does not need
an SVG runtime dependency.

Reference collection: https://www.iconfont.cn/collections/index?type=4
