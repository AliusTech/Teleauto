# Icon assets

Public UI icons use a single monochrome vector style. Source replacements may be downloaded as SVG from
Alibaba Iconfont monochrome collections: https://www.iconfont.cn/collections/index?type=4

Before adding an asset, record its Iconfont detail URL, collection/author and licence here. Normalize it to a
24×24 viewBox with rounded line endings and use Android tint for state colour; do not embed state colours.

`ic_dji_controls.svg` and `ic_dji_video_actions.svg` are the project-owned baseline control sets
(chevron, center, expand, collapse, play, focus, record and photo).
They define the same 24×24, 1.8px rounded-line contract that imported Iconfont assets must follow. They are not
attributed to Iconfont. Any future Iconfont replacement must include its exact detail URL and licence below.
